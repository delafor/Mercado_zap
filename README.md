# MercadoZap

> Aplicativo de pedidos para pequenos comércios locais, desenvolvido em Flutter como um dos meus primeiros projetos completos durante minha fase inicial de aprendizado no desenvolvimento mobile.

## 📌 Sobre o projeto

O **MercadoZap** nasceu com a ideia de criar uma solução simples para pequenos mercados e comércios locais que ainda realizam seus pedidos principalmente através do WhatsApp.

A proposta era permitir que o cliente acessasse o aplicativo ou sua versão web, encontrasse os produtos disponíveis, adicionasse os itens ao carrinho e realizasse o pedido de forma organizada.

Após a confirmação, as informações do pedido poderiam ser encaminhadas através da integração com o WhatsApp, facilitando a comunicação entre o cliente e o estabelecimento.

O projeto foi inspirado em uma necessidade observada em um comércio local, que já utilizava o WhatsApp como principal meio para receber pedidos. A ideia foi utilizar essa mesma dinâmica, mas tornando o processo mais organizado e simples para o cliente.

---

## 🎯 Objetivo

O objetivo principal do MercadoZap era desenvolver uma solução acessível para pequenos comércios que desejassem disponibilizar seus produtos online sem precisar construir uma estrutura de e-commerce complexa.

A aplicação foi pensada para:

- Facilitar a visualização dos produtos.
- Permitir pesquisa e filtragem de produtos.
- Criar um carrinho de compras.
- Calcular o valor do pedido.
- Coletar os dados de entrega do cliente.
- Organizar os itens escolhidos em um pedido.
- Enviar as informações do pedido através do WhatsApp.
- Servir como uma alternativa simples aos processos manuais de pedidos.

## 📱 Aplicação

A aplicação foi pensada para funcionar como uma experiência de compra simples:

```text
Produtos
   ↓
Pesquisa / Categorias
   ↓
Carrinho
   ↓
Checkout
   ↓
Dados de entrega
   ↓
Confirmação do pedido
   ↓
WhatsApp
```

A ideia era manter o processo simples tanto para o cliente quanto para o pequeno comércio.

## ⚠️ Por que o projeto foi descontinuado?

O MercadoZap foi desenvolvido durante uma fase em que eu ainda estava adquirindo os fundamentos de Flutter e desenvolvimento de software.

Conforme o projeto cresceu, algumas decisões tomadas no início começaram a dificultar sua manutenção e evolução. Como eu ainda tinha pouca experiência, acabei criando partes da aplicação de maneiras que hoje considero inadequadas.

Com o tempo, o projeto acabou se tornando mais difícil de organizar e manter. Ao mesmo tempo, meus conhecimentos foram evoluindo e minha visão sobre arquitetura, organização de código e desenvolvimento de aplicações também mudou.

Em determinado momento, continuar adicionando funcionalidades sobre essa estrutura deixou de fazer sentido.

Por isso, decidi **descontinuar o desenvolvimento do MercadoZap**.

A decisão não significa que o projeto deixou de ter valor. Pelo contrário: ele passou a ter um novo propósito.

## ▶️ Como executar

### Pré-requisitos

Antes de executar o projeto, é necessário ter instalado:

- [Flutter](https://flutter.dev/)
- [Dart](https://dart.dev/)
- Android Studio ou outro ambiente compatível
- Um dispositivo físico ou emulador

### Instalação

Clone o repositório:

```bash
git clone <URL_DO_REPOSITORIO>
```

Entre na pasta:

```bash
cd <NOME_DO_PROJETO>
```

Instale as dependências:

```bash
flutter pub get
```

Execute o projeto:

```bash
flutter run
```

> Algumas funcionalidades podem exigir configurações adicionais de serviços externos e credenciais que não fazem parte deste repositório.
